## 📋 1. Search Engine Verification & Ownership

- [x] **Repository Meta Tags**: OpenGraph (`og:title`, `og:description`, `og:image`), Twitter Card, and Google Author metadata added to [`public/index.html`](public/index.html).
- [x] **PWA Manifest & Icons**: [`public/manifest.json`](public/manifest.json) configured with `name`, `short_name`, `categories: ["photo", "utilities", "social"]`.
- [ ] **Google Search Console (GSC)**:
  - Add property URL (e.g. GitHub Pages or custom domain).
  - Upload Google HTML verification file `google<token>.html` or DNS TXT verification.
  - Submit `sitemap.xml`.
- [ ] **Bing Webmaster Tools**:
  - Connect via Google Search Console auto-import or add `BingSiteAuth.xml`.
